Write a class that implements an LRU (Least Recently Used) cache with O(1) time
complexity for both get and put operations. The cache has a fixed capacity and
evicts the least recently used item when full.

Your class must be declared as follows:

class LRUCache:
    def __init__(self, capacity: int):
    def get(self, key: int) -> int:
    def put(self, key: int, value: int) -> None:

The class should:
- Initialize with a positive integer capacity
- get(key): Return the value if key exists, -1 otherwise
- put(key, value): Insert or update the key-value pair
- When capacity is reached, evict the least recently used item before inserting
- Both get and put operations count as "using" the key
- Implement using a combination of dict and doubly linked list

Examples:

cache = LRUCache(2)
cache.put(1, 1)
cache.put(2, 2)
cache.get(1)        # Returns 1
cache.put(3, 3)     # Evicts key 2
cache.get(2)        # Returns -1 (not found)
cache.put(4, 4)     # Evicts key 1
cache.get(1)        # Returns -1 (not found)
cache.get(3)        # Returns 3
cache.get(4)        # Returns 4

cache = LRUCache(1)
cache.put(2, 1)
cache.get(2)        # Returns 1
cache.put(3, 2)     # Evicts key 2
cache.get(2)        # Returns -1
cache.get(3)        # Returns 2
